# `@hexkit/plugin-drizzle`

Drizzle ORM persistence adapter generator for Hexkit. It produces database
schemas, repository implementations, mappings, and query adapters for PostgreSQL
**derived from Apical contracts and hexagonal ports**.

This plugin implements the repository ports generated by the hexagonal
architecture package while keeping persistence concerns outside the core. Sample
relations such as Pet↔Order appear only when present in the input contract /
dogfood fixture—not as literals in this package (see PRD §5.0).
