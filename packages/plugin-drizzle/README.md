# `@hexkit/plugin-drizzle`

Drizzle ORM persistence adapter generator for Hexkit. It produces database
schemas, repository implementations, mappings, and query adapters for PostgreSQL
**derived from Apical contracts and hexagonal ports**.

This plugin implements the repository ports generated by the hexagonal
architecture package while keeping persistence concerns outside the core. Sample
relations such as Pet↔Order or Book→Author appear only when present in the input
contract / fixture—not as literals in this package (see PRD §5.0).

## Column mapping

Only component schemas that declare `x-hexkit.persistence` become tables. Other
schemas still get Apical craft modules and hexagonal domain types; they do not
get migrations or repository adapters.

For each property on a persisted schema:

| OpenAPI shape                             | Persistence                                           |
| ----------------------------------------- | ----------------------------------------------------- |
| Nested `object`, `array`, or `$ref`       | Postgres **JSONB** (not `json`)                       |
| Scalar `x-hexkit.reference`               | Foreign key to the named persisted schema (unchanged) |
| `boolean` / `integer` / `string` (± enum) | Matching scalar column                                |

A property cannot combine `$ref` with `x-hexkit.reference`. Use a scalar
foreign-key property, or omit `x-hexkit.reference` to store the nested value as
JSONB. Declaring `x-hexkit.persistence` on a _referenced_ schema does **not**
turn an embed into a relation; that opt-in is a later Phase 2 feature (see
[Rich Pet nested persistence](../../docs/superpowers/plans/2026-08-20-rich-pet-nested-persistence.md)).
